# نظام مراقبة ذكي بالأردوينو + تعلم الآلة

مشروع يقرأ قراءات حساسات من أردوينو (حرارة، رطوبة، صوت، ماء، LM35) عبر المنفذ التسلسلي،
ويستخدم نموذج **Decision Tree** لتصنيف الحالة، ثم يرسل النتيجة للأردوينو حتى يتصرف.

## الحالات

| الحالة   | الكود المرسل للأردوينو | الوصف |
|----------|------------------------|-------|
| `normal` | `n` | الوضع طبيعي |
| `noise`  | `o` | ضوضاء عالية |
| `water`  | `w` | تم كشف ماء |
| `hot`    | `h` | الحرارة ارتفعت ≥ 2° عن حرارة الغرفة الأولية |

## الملفات

| الملف | الوظيفة |
|-------|---------|
| `collect.py` | يجمع 100 قراءة من الأردوينو ويضيفها لـ `data.csv` مع التصنيف المعطى |
| `train.py` | يدرّب النموذج على عمودي `sound` و `water` ويحفظه في `model.pkl` |
| `live.py` | يشغّل النموذج مباشرة على القراءات ويرسل الحالة للأردوينو |
| `test_hw.py` | يختبر استجابة الأردوينو لكل الأكواد |
| `data.csv` | بيانات التدريب الحالية |
| `data_old.csv` | بيانات قديمة |
| `model.pkl` | النموذج المدرّب |

## صيغة البيانات من الأردوينو

كل سطر على المنفذ التسلسلي (9600 baud) لازم يكون 5 قيم مفصولة بفواصل:

```
temp,hum,sound,water,lm35
```

## التشغيل

```bash
pip install -r requirements.txt
```

```bash
python collect.py normal   # كرر لكل حالة: normal / noise / water
```

```bash
python train.py
```

```bash
python live.py
```

> المنفذ مضبوط على `COM3` — غيّره داخل الملفات إذا كان الأردوينو على منفذ آخر.
